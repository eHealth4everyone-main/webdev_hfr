# Healthcare Facility Registry - Implementation Summary

This document summarizes the new features and improvements added to the HFR system.

---

## 🚀 1. Automated Level Determination
**Goal:** Automatically calculate the facility level (Primary, Secondary, Tertiary) based on staff count, bed capacity, and available services.

### Implemented Logic (Provisional)
*   **Tertiary:**
    *   `Doctors > 20` **AND** `Beds > 100` **AND** at least one specialized service: `hs_outpatient_surgery`, `hs_inpatient_int_care_service`, **OR** `onsite_imaging`.
*   **Secondary:**
    *   `5 <= Doctors <= 20` **AND** `30 <= Beds <= 100` **AND** at least one secondary service: `hs_outpatient_obstetrics`, `onsite_laboratory`, **OR** `ambulance_services`.
*   **Primary:**
    *   Matches all remaining cases, typically `< 5 Doctors` and `< 30 Beds`.

### Backend Changes:
*   Created `App\Services\FacilityLevelService.php` to encapsulate this logic.
*   Modified `HospitalsController@store` and `HospitalsController@update` to call this service automatically on save/update.
*   Modified `MyRequestController@updateRequest` to also trigger automatic level determination.

### Frontend Changes:
*   Added a **Suggest Level** link next to the "Hospital/ Clinic Level" label in the Create and Edit facility forms.
*   This triggers an AJAX call to calculate and set the best-fit level based on current form inputs.

---

## 🎓 2. Certificate of Standards Issuance
**Goal:** Replace hardcoded values with a dynamic verification system and autogenerated certificates for published facilities.

### Implementation:
*   **Database:** Created `hs_facility_certificates` table to store certificate number, issue date, expiry date, and status.
*   **Logic:**
    *   Modified `PublishController@store` to automatically issue a certificate upon the **final publication** of a new facility.
    *   Modified `HospitalsController@showCertificate` to auto-issue a certificate if one doesn't exist for a published facility when trying to view it.
    *   Implemented `CertificateService.php` to handle certificate number generation (format: `HFR-STATECODE-LGACODE-XXXX`) and expiry (typically 1 year).
*   **PDF/View:**
    *   Created a professional **Certificate of Standards** template using Blade (`resources/views/hospitals/certificate.blade.php`).
    *   Includes a unique QR code (placeholder ready), official seals, and signatures.
    *   Added a Print functionality with optimized landscape layout.

### Frontend Integration:
*   The `FacilityDetails.tsx` component now fetches and displays certificate information.
*   A **"View Official Certificate of Standards"** button appears only if a certificate has been issued for the facility.
*   Integrated the `Certificate` React component for a seamless viewing experience within the portal.

## 🛠 3. Database Updates
**SQL Script:** `backend_v2/create_certificate_system.sql`
*   Adds the `hs_facility_certificates` table.
*   Adds the `ambulance_services` column to `hs_hospitals` and `hs_hospitals_history` to support the new "Secondary" criteria.
